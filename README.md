# 삼국지택틱스

2등신 장수들과 함께하는 쿼터뷰 삼국지 전략 RPG (유비 · 관우 · 장비의 도원결의부터 한중왕까지 5장)

**기획 · 제작: 박상민**

**▶ 플레이: https://scarfhero628-star.github.io/samguk-tactics/**

## 휴대폰 홈 화면에 설치하기

- **안드로이드 (크롬 · 삼성 인터넷)**: 위 주소를 열고 화면을 한 번 누른 뒤, 타이틀의 **[앱으로 설치]** 버튼을 누르세요. (또는 브라우저 메뉴 → 홈 화면에 추가)
- **아이폰 · 아이패드 (사파리)**: 위 주소를 열고 공유 버튼 □↑ → **홈 화면에 추가** → 추가.
- 한 번 열어 두면 그다음부터는 인터넷 없이도 실행돼요. 휴대폰은 가로로 들고 하세요.
- PC에서 게임을 켜면 타이틀 왼쪽 아래 「휴대폰으로 하기」 QR을 휴대폰 카메라로 찍어 바로 받을 수 있어요.

## 만든 사람과 도구

기획 · 제작 박상민 · 이미지 Kling AI · 음악 Suno · 개발 Claude
